# 数学原論

ブルバキ『数学原論』の構造的・公理的な思想を参照し、独立した論考の集積ではなく、全巻を通じて論理的に整合する数学書の叢書を制作する。擬コンラットとは別の企画である。

## 制作管理
- [AGENTS.md](AGENTS.md)：AIを含む執筆者の共通指示
- [制作方法論](docs/methodology.md)：執筆・検証・改訂の手順
- [知識・依存関係台帳](docs/knowledge.md)：各段階で導入済みの知識、前提、公理、定義、結果、依存関係の唯一の正本

各原稿と台帳を対応させ、先行する知識だけで論証できる体系を目指す。論理的順序と実際の制作順序は区別する。

初期化日：2026-11-26。現時点では数学的原稿は未制作であり、基礎公理系・全巻の詳細構成も未確定である。
