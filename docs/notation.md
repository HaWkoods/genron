# 記号・記法一覧（第2版）

記号とその指示対象を一行ずつ掲げる。参照付き項目は既刊ノートの知識台帳に対応する。参照のない項目は先行記法であり、定義の確立を意味しない。同一文脈で衝突する記号は添字又は説明で区別する。
