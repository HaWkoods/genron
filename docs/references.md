# 参考文献の調査・利用規約

制定：2026-11-26。

## 資料の選択
- 各ノートの構成案を作る前に、接続された Google Drive にあるユーザー所蔵の数学書・論文・講義ノートを積極的に検索する。日本語・英語の主題名、著者名、書名、関連用語を適宜用いる。
- 所蔵資料を優先的な調査対象とするが、適切な資料がない場合や内容が不十分な場合は、公開されている信頼できる文献も補足する。
- ブルバキの思想・体系を参照しつつ、当該主題に適した複数の文献を比較し、必要な仮定、定義の相違、証明方法、理論の一般性、既存の依存グラフとの整合性を調べる。文献の配列をそのまま採用しない。

## 調査・引用
- ファイル名や検索結果だけで参照済みとしない。可能な限り該当箇所の本文を確認する。
- 実際に参照した文献について、著者、書名・論文名、版・刊行情報（確認できる範囲）、章節・頁、利用目的を原稿の参考文献・制作記録等に記す。確認できない事項は捏造せず、不明とする。PDF頁と冊子の頁が異なる場合は区別する。
- 引用と数学原論独自の定義・論証・構成を区別する。証明は理解した上で独自の記述に再構成し、直接引用は必要最小限とする。
- 原論で使用する結果は、文献に記載されているだけでは使用可能としない。原論の台帳に登録された前提から論証するか、明示的に採用した公理・背景知識として登録する。外部文献の引用で循環や論証の欠落を隠さない。
- 文献間の定義や仮定の違いは原論の統一規約に照らして処理する。依存先が増減する場合は知識台帳を更新する。
- 原稿への参考文献記載は通常の書誌情報を用いる。ユーザーの所蔵PDF本体、非公開のDriveリンクや認証情報は、明示的な指示と権利上の根拠がない限りGitHubへ転載しない。資料を勝手に移動・変更・共有しない。

## 報告
参照した資料、実際に確認した範囲、確認できなかった資料・箇所、採用した論証方法と理由を制作報告に含める。閲覧不能の場合はその制約を明記する。現時点では個別ノート未制作のため、特定文献の採用は未決定である。
