# 総目次初版の設計記録

2026-11-26。50ノートの計画を knowledge.json の notes に登録した。閲覧用の総目次は roadmap.md で自動生成する。以下は設計理由であり、個別の知識や計画の重複台帳ではない。

## 設計上の判断

- 数学的言語と素朴集合論を根とし、選択公理は独立した初期ノートに分離する（素朴集合論の一部）。基本的な代数・順序・位相は形式的論理学を要求しない。
- 整列と極大原理で必要となる初等的な整列・超限再帰は、選択公理の応用に必要な限り先行して扱う。公理的集合論の形式化、独立性等とは区別する。
- 実数は有理数の Dedekind 切断などによる順序的構成を候補とする。実数値距離を使う完備化から実数を構成する循環を避ける。一般位相の初歩は実数に依存させない。
- 有限次元線形代数を任意次元の基底存在から切り離す。選択公理の使用を必要な証明だけに限定する。
- 圏論は具体的な群・位相等を見た後の構造の抽象化とする。代数や解析の基本部分は圏論の完了を待たない。サイズの問題は実際に必要となる時点で明示する。
- 数理論理学と現代的集合論は後続の枝とし、全数学の終了まで待つという意味ではなく、必要な数学的手段を得た段階で研究可能とする。
- 各ノートが大きすぎる場合や、前提が過剰である場合は分割・再編する。計画上の辺は候補であり、最小の依存を証明済みとはしない。例えば距離空間の可算選択を用いる結果、加群の任意次元基底、位相線形空間の一般論等は将来の分割候補である。自然数の存在・再帰、集合の存在原理、各ノートの定義流儀を執筆前に精査する。

## 文献調査

Google Drive 所蔵資料を調査し、次の4冊について冒頭の抽出テキストを確認した。本文全体の精読ではない。

- Serge Lang, Algebra, revised third edition, Springer, 2002, Foreword（v–vi 頁の範囲）：数学書の線形配列と数学の並行的な構造の区別、代数の基礎から代数方程式と線形・多重線形代数への分岐を設計の参考にした。
- Saunders Mac Lane, Categories for the Working Mathematician, second edition, Springer, Preface to the First Edition：圏・函手・自然変換から普遍性、極限、随伴へ進む構成を圏論ノートの目標設定の参考にした。
- Thomas Jech, Set Theory, third millennium edition, revised and expanded, Springer, 2002/2003, Preface and table of contents（Part I, Chs. 1–12 および Part II 冒頭）：形式的集合論、順序数、選択公理、モデル、強制法の範囲を調べ、原論では素朴な操作・選択公理と後続の形式的研究を分離する方針を確認した。
- Glen E. Bredon, Topology and Geometry, Springer, 1993, Preface（v–vi 頁の範囲）：一般位相、ホモトピー、多様体、代数的位相の関連を参考にした。

その他、所蔵ファイル名の検索により、可換環論、代数幾何、函数解析、測度論、微分多様体、複素解析、最適化、確率過程、数理金融、ホモロジー代数、整数論の文献候補を確認した。これらは未精読であり、個々のノートの構成決定前に本文を調べる。非公開Driveリンク及びPDF本体は転載しない。
