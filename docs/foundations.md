# 基礎言語と数理論理学・現代的集合論の位置づけ

制定：2026-11-26。

## 基本理念

数学を営むための言語と、その言語を数学的対象として研究する理論を区別する。原論の初期段階に数理論理学・公理的集合論の体系的な学習を要求しない。数学的推論と素朴な集合の言語を用いて数学を展開し、その後、数学的手法を論理・集合自体に適用する発展的・応用的な枝として数理論理学および現代的集合論を扱う。「応用」はこの叢書内での位置づけであり、一般的な学問分類の主張ではない。

## 冒頭における論理記号の導入

原論の冒頭では、論理記号を自然言語による数学的文章の省略記号として定める。論理式・命題・述語等を形式的対象として先に定義することはしない。以下を標準的な記法とする（P, Q は既に意味を持つ数学的な言明を表すための仮の文字であり、形式言語の構文変項ではない）。

| 記法 | 自然言語による読み・意味 |
|---|---|
| ¬P | P ではない |
| P ∧ Q | P かつ Q |
| P ∨ Q | P または Q（両方の場合も含む） |
| P ⇒ Q | P ならば Q |
| P ⇔ Q | P であることと Q であることは同値である |
| ∀x P(x) | 考えている範囲の任意の x について P(x) が成り立つ |
| ∃x P(x) | 考えている範囲に P(x) を満たす x が存在する |
| ∃!x P(x) | 考えている範囲に P(x) を満たす x がただ一つ存在する |

量化する対象の範囲を文章または記号で明示する。集合・所属の記法を導入した後は、∀x∈A, P(x) を「A の任意の元 x について P(x) が成り立つ」、∃x∈A, P(x) を「A の元 x で P(x) を満たすものが存在する」と読む。量化や結合の作用範囲が曖昧にならないよう括弧または文章を用いる。

この段階で真理値、真理表、構文の帰納的定義、形式的意味論、証明体系等を導入しない。通常の数学的推論は背景として用いる。記号の導入は自然言語に基づく記法の規約であって、論理そのものの形式的構成ではない。後続の数理論理学における形式的な記号と区別する。上表は執筆規約であり、正式原稿に収録する際に規約として知識台帳へ登録する。

## 初期段階で許容すること

通常の数学的文章、等号、論理結合子、量化、基本的な古典的推論（背理法等）、集合・元・所属の素朴な言語を使用する。これらを初めから形式言語として定義・公理化することはしない。写像、関係、同値関係、商集合、積集合、順序等は、必要な構造を展開するために適切な段階で導入する。自然数・帰納法その他の背景知識をどこまで仮定するかは個別に定める。

素朴な集合の言語を用いることは無制限内包原理を許すことではない。集合の存在、選択公理、整列定理、Zorn の補題、無限集合に関する存在原理などを必要とする際には、導入済みの結果で証明するか、採用する背景原理として明示し、適用範囲と依存関係を記録する。初期の運用方針は特定の形式的公理系（ZFC 等）を採用したことを意味しない。

## 後続の枝

命題論理・述語論理の形式化、形式的証明、モデル理論、完全性・不完全性、計算可能性、公理的集合論、順序数・基数の発展理論、独立性・強制法等は、必要な先行数学を利用して展開する後続の研究対象とする。基本的な集合操作や初等的な濃度・順序の議論まで一律に禁止する趣旨ではない。具体的なノートの分割、前提、導入時点は今後定める。

## 依存関係の取扱い

初期の背景原理と、それを後続の形式体系内で表現・研究する結果を区別する。後続ノートで初期数学を形式化・再構成しても、初期の知識の成立根拠をその後続ノートに遡及的に依存させてはならない。背景として許容する推論の運用は台帳の foundation に記し、個別に必要な実質的な集合存在原理・追加公理等は知識台帳に登録し、依存先を明記する。形式化された対応物と背景原理を別個の項目として管理する。
