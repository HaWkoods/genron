# 基礎言語と数理論理学・現代的集合論の位置づけ

制定：2026-11-26。

## 基本理念

数学を営むための言語と、その言語を数学的対象として研究する理論を区別する。原論の初期段階に数理論理学・公理的集合論の体系的な学習を要求しない。数学的推論と素朴な集合の言語を用いて数学を展開し、その後、数学的手法を論理・集合自体に適用する発展的・応用的な枝として数理論理学および現代的集合論を扱う。「応用」はこの叢書内での位置づけであり、一般的な学問分類の主張ではない。

## 冒頭における論理記号の導入

原論の冒頭では、論理記号を自然言語による数学的文章の省略記号として定める。論理式・命題・述語等を形式的対象として先に定義することはしない。以下を標準的な記法とする（P, Q は既に意味を持つ数学的な言明を表すための仮の文字であり、形式言語の構文変項ではない）。

| 記法 | 自然言語による読み・意味 |
|---|---|
| ¬P | P ではない |
| P ∧ Q | P かつ Q |
| P ∨ Q | P または Q（両方の場合も含む） |
| P ⇒ Q | P ならば Q |
| P ⇔ Q | P であることと Q であることは同値である |
| ∀x P(x) | 考えている範囲の任意の x について P(x) が成り立つ |
| ∃x P(x) | 考えている範囲に P(x) を満たす x が存在する |
| ∃!x P(x) | 考えている範囲に P(x) を満たす x がただ一つ存在する |

量化する対象の範囲を文章または記号で明示する。集合・所属の記法を導入した後は、∀x∈A, P(x) を「A の任意の元 x について P(x) が成り立つ」、∃x∈A, P(x) を「A の元 x で P(x) を満たすものが存在する」と読む。量化や結合の作用範囲が曖昧にならないよう括弧または文章を用いる。

この段階で真理値、真理表、構文の帰納的定義、形式的意味論、証明体系等を導入しない。通常の数学的推論は背景として用いる。記号の導入は自然言語に基づく記法の規約であって、論理そのものの形式的構成ではない。後続の数理論理学における形式的な記号と区別する。上表は執筆規約であり、正式原稿に収録する際に規約として知識台帳へ登録する。

## 冒頭から素朴集合論への展開順序

初期ノートの導入順序を次の通りとする。

1. 自然言語の省略としての基本的な論理記号。
2. 既に導入した論理記号を組み合わせた式の、さらなる略記法。
3. 通常の数学的推論による基本的な論理法則の確認。
4. 素朴集合論（集合と元、集合の相等、部分集合、集合の構成と演算、写像・関係等）。

第2段階の制限付き量化に先立って、集合 A および x∈A を「x は A の元である」という自然言語の略記としてのみ説明する。この時点では集合の存在原理や集合演算の理論は展開しない。

### 論理記号を組み合わせた略記

- ∀x∈A, P(x) は ∀x (x∈A ⇒ P(x)) の略記とする。
- ∃x∈A, P(x) は ∃x (x∈A ∧ P(x)) の略記とする。
- ∃!x P(x) は ∃x (P(x) ∧ ∀y (P(y) ⇒ y=x)) の略記としても表せる。y は新しい変数とし、量化範囲は x と同じとする。等号は自然言語の「同じである」の記法として先に確認する。
- ∀x,y∈A, P(x,y) は ∀x∈A, ∀y∈A, P(x,y) の略記とする。存在量化についても同様。
- x∉A は ¬(x∈A)、x≠y は ¬(x=y) の略記とする。
- 異なる種類の量化の順序を無断で入れ替えない。括弧、変数の束縛範囲、対象範囲、変数の衝突に注意する。

ここでの無制限風の量化も、文脈で指定された対象範囲内での量化である。A の元はその範囲に含まれるものとする。空集合に対する全称・存在言明の読み方も明示する。

### 論理法則

自然言語での古典的推論に基づき、数学的文章の読み替えや論証に直接必要な法則を扱う。形式体系内の定理として証明するのではなく、通常の推論によって双方の含意を示すなどして確認する。

候補：二重否定、排中律、矛盾律、交換・結合・分配律、De Morgan の法則、対偶、含意の合成、同値関係としての言明の同値、量化の否定、同種量化の交換、量化と連言・選言の適切な分配、直接証明・対偶による証明・背理法・場合分け。各法則は必要な条件（変数の自由な出現、対象範囲、空の範囲等）を明示し、成り立たない一般化を避ける。排中律等は採用する古典的推論の背景原理であり、他の法則から無前提で導いたと主張しない。

### 素朴集合論への移行

上記の論理記法・法則を用いて、集合と元、外延性（集合の相等）、部分集合、集合の指定、空集合、対・和・共通部分・差、冪集合、直積、写像、関係等へ進む。集合の存在と定義の略記を区別し、必要な存在原理を明示する。無制限内包を許さない。具体的な章節の分割と項目の依存関係は文献調査を経て正式原稿・台帳で確定する。

### 選択公理

素朴集合論において、選択公理を定理ではなく独立に採用する公理として明示する。写像・添字集合・集合族・合併集合の導入後、選択公理を次の形で述べる。

任意の集合 I および空でない集合からなる任意の集合族 (A_i)_{i∈I} に対し、写像 f: I → ⋃_{i∈I} A_i であって、すべての i∈I について f(i)∈A_i を満たすものが存在する。

個々の集合が元を持つという事実と、すべての集合から同時に元を選ぶ写像の存在を区別する。有限個の場合は必要な有限集合の理論を整備した後、選択公理によらず論証できることを説明する。直積の非空性による定式化は直積の定義の後に扱う。

整列定理・Zorn の補題は必要な順序・集合の理論の整備後に選択公理との関係を論証する。形式的な独立性の証明は後続の現代的集合論に委ねる。選択公理の明示的な採用は ZFC 全体の採用を意味しない。

正式原稿では選択公理に恒久 ID を付与して kind: axiom として知識台帳に登録する。直接使用する項目には依存を注釈し、間接的な依存も追跡可能にする。選択公理を必要としない結果には不必要な依存を付与しない。選択公理に依存する証明と、命題そのものが選択公理なしには証明できないという主張を混同しない。

## 初期段階で許容すること

通常の数学的文章、等号、論理結合子、量化、基本的な古典的推論（背理法等）、集合・元・所属の素朴な言語を使用する。これらを初めから形式言語として定義・公理化することはしない。写像、関係、同値関係、商集合、積集合、順序等は、必要な構造を展開するために適切な段階で導入する。自然数・帰納法その他の背景知識をどこまで仮定するかは個別に定める。

素朴な集合の言語を用いることは無制限内包原理を許すことではない。集合の存在、選択公理、整列定理、Zorn の補題、無限集合に関する存在原理などを必要とする際には、導入済みの結果で証明するか、採用する背景原理として明示し、適用範囲と依存関係を記録する。初期の運用方針は特定の形式的公理系（ZFC 等）を採用したことを意味しない。

## 後続の枝

命題論理・述語論理の形式化、形式的証明、モデル理論、完全性・不完全性、計算可能性、公理的集合論、順序数・基数の発展理論、独立性・強制法等は、必要な先行数学を利用して展開する後続の研究対象とする。基本的な集合操作や初等的な濃度・順序の議論まで一律に禁止する趣旨ではない。具体的なノートの分割、前提、導入時点は今後定める。

## 依存関係の取扱い

初期の背景原理と、それを後続の形式体系内で表現・研究する結果を区別する。後続ノートで初期数学を形式化・再構成しても、初期の知識の成立根拠をその後続ノートに遡及的に依存させてはならない。背景として許容する推論の運用は台帳の foundation に記し、個別に必要な実質的な集合存在原理・追加公理等は知識台帳に登録し、依存先を明記する。形式化された対応物と背景原理を別個の項目として管理する。

この規約は叢書の展開方法の決定であり、数学の無矛盾性を証明したものではない。
