## 構成と方針

無限公理 K-000098 を採用し、自然数を最小の帰納的集合として構成した。0を含む。帰納法・再帰定理、加法・乗法、有限集合の濃度、有限選択を論証する。選択公理は使用しない。自然数の構成は von Neumann 型を採用した。

## 参考文献調査

Google Drive 所蔵の Jech, Set Theory, Third Millennium Edition, Springer, 2003, Ch. 1 (Infinity), Ch. 2 (Ordinal Numbers), Ch. 3 (Exercises 3.1 等)。無限公理、最小帰納的集合、有限集合の記述を参照した。 抽出テキストの確認であり、全篇精読ではない。証明は原論の既出の理論から独自に再構成した。Mac Lane, Categories for the Working Mathematician, 2nd ed., の自然数対象・再帰の記述も調査したが、圏論を前提としない。
