## 構成と方針

集合の外延性、空集合、対集合、部分集合の指定、合併集合、冪集合、一意指定による集合の存在を実質的な原理として明示した（形式的なZFの体系の研究はしない）。本篇では対象を集合として扱う。無限集合の存在と選択公理はまだ使わない。順序対を構成し、写像は始域・終域・グラフを含む対象とする。集合族の積と非交和、商集合の普遍性及び写像の標準分解を、代表元の一斉選択に依存せずに証明した。空の添字集合と共通部分の母集合、空集合からの写像等の退化例を明示した。採用した集合存在原理と写像の定義は制作上の判断であり、利用者の校訂を受けて改訂可能。

## 文献調査

- T. Jech, Set Theory, 3rd Millennium ed., revised and expanded, Springer, 2003, Ch.1。集合存在原理と順序対の定義の該当抽出テキストを確認し、原理を自然言語で明示する構成の参考とした。
- J. M. Lee, Introduction to Topological Manifolds, 2nd ed., Springer, 2011, Appendix A。Cartesian Products, Relations, and Functions（p.384 ff.）、Indexed Families（p.391 ff.）の関連抽出テキストを確認した。順序対、直積、関係、非交和の記述を比較した。Leeの非交和の順序対と異なり、本篇では添字を第一成分とする。
