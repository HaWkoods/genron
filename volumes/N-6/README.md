## 構成と方針

整列集合と始切片、超限帰納・再帰（固定した集合を値域とする版）、整列集合の比較、Hartogs の定理を順序数の一般理論に先立ち構成した。Hartogs の証明は部分集合の整列順序の同型類を用い、選択公理を使用しない。整列定理・Hausdorff の極大原理・Zorn の補題の同値性を論証する。空の鎖も含める。
