## 構成と方針

選択函数、一意選択、二つの集合からの選択、選択公理、任意の集合族の直積の非空性、右逆・左逆、全射の右逆の存在による同値な定式化、関係の函数化、商写像の切断と代表元、全射の積を扱う。選択公理を公理として明示し、恒久ID K-000060 を付与した。選択公理を必要としない一意選択や一つ・二つの集合からの選択と区別する。空の添字集合、空集合からの単射の左逆の例外を明示した。整列定理とZornの補題との同値は N-6 で扱い、有限選択の一般的な論証は N-5 に委ねる。選択公理の形式的独立性は後続の現代的集合論の対象とする。
