## 構成と方針

濃度は全単射・単射の存在を表す関係として導入し、集合としての基数を先取りしない。Cantor–Bernstein の定理、Cantor の定理、高々可算集合、可算無限集合を扱う。可算族の合併については単射の族が与えられている場合の主張に限定し、選択公理を使用しない。
